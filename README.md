## 🚀 Featured Projects

### 🧠 AI-Powered Credit Risk Engine
> *Replacing black-box lending decisions with transparent, auditable AI*

Financial institutions reject or approve millions of loan applications through opaque models. This system changes that.

- **Stack:** Python · FastAPI · LangGraph · Groq API · Logistic Regression · Random Forest · Gradient Boosting
- **Architecture:** Weighted ensemble scoring across 3 models → FastAPI REST layer → LangGraph agentic workflow → LLM-generated, policy-compliant lending rationale
- **Key insight:** Flags high-variance model disagreements for manual review — the system knows when it doesn't know
- **Output:** Fully explainable underwriting decisions that a compliance officer can audit

[![GitHub](https://img.shields.io/badge/Source-181717?style=for-the-badge&logo=github)](https://github.com/naveendhaterwal/AI-Powered-Credit-Risk-Engine)
[![Demo](https://img.shields.io/badge/Live_Demo-00D4FF?style=for-the-badge&logo=vercel)](https://gen-ai-2.vercel.app/)

### 💸 SolUPI — UPI-to-Solana On-Ramp
> *Eliminating P2P risk from crypto on-ramps in emerging markets*

Getting USDC in India means trusting strangers on P2P platforms or paying centralized exchange premiums. SolUPI removes both problems.

- **Stack:** Next.js · TypeScript · Node.js · PostgreSQL · Solana Web3.js · JWT · Framer Motion
- **Architecture:** User pays via UPI → automated RRN verification → trustless on-chain USDC settlement on Solana
- **Non-custodial:** No one holds your funds at any stage of the transaction flow
- **Production-deployed** on Vercel + Render with paginated order history and JWT auth

[![GitHub](https://img.shields.io/badge/Source-181717?style=for-the-badge&logo=github)](https://github.com/naveenkumar29052006/SolUPI-V2)
[![Demo](https://img.shields.io/badge/Live_Demo-00D4FF?style=for-the-badge&logo=vercel)](https://sol-upi-v2.vercel.app/)
